# Design language

> Seeded by `/annotate` because this project had no design document.
> Every section below is empty on purpose. Fill a section when you make a
> decision, not before — an invented value is worse than a blank one, because
> the next person can't tell the two apart.
>
> **Not yet decided** means exactly that: no decision has been made, so
> anything goes for now. Delete the marker when you replace it.
>
> Each entry should carry **the decision, and why**. A list of values is a
> palette; a list of values with reasons is a language.
